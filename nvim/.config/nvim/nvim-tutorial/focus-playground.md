# Focus-mode playground

The purpose of this file is simply to have enough nested prose and headings to
make Twilight and Zen Mode visually obvious.

## Current section

Put your cursor in this paragraph and toggle Twilight with `<leader>tw`. Text
outside the active syntactic context should become less prominent, making the
current area easier to focus on.

This is another paragraph in the same section. Toggle Zen Mode with
`<leader>tz` and inspect the narrower centered editing area. The configured Zen
window hides the sign column, line numbers, relative numbers, cursorline and
cursorcolumn.
